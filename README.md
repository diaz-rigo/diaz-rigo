## 🚀 Sobre mí

<img align="right" width="380" src="https://raw.githubusercontent.com/DenverCoder1/DenverCoder1/main/octocat.svg" alt="coding illustration" />

Soy un **desarrollador web fullstack** apasionado por construir productos digitales sólidos y automatizar procesos que ahorran tiempo y esfuerzo.

- 🔭 Trabajo principalmente con **Python, JavaScript y TypeScript**
- 🌐 Construyo interfaces con **Angular** y APIs con **Node.js, Flask y Django**
- 🤖 Automatizo flujos de trabajo con **Selenium**
- 📚 Siempre aprendiendo nuevas herramientas y buenas prácticas
- 💬 Pregúntame sobre desarrollo web, automatización o arquitectura de software
